# Support

| You need | Go to |
|---|---|
| Help to install or use UndoTurn | [User guide](docs/GUIDE.md), then [Discussions, Q&A](https://github.com/HugoLopes45/undoturn/discussions/categories/q-a) |
| To report a bug | [New issue, Bug report](https://github.com/HugoLopes45/undoturn/issues/new/choose) |
| To report lost files, overwritten files or exposed data | [Private vulnerability report](https://github.com/HugoLopes45/undoturn/security/advisories/new). Do not open a public issue. |
| Support for a new agent | [New issue, Agent support](https://github.com/HugoLopes45/undoturn/issues/new/choose) |
| To discuss an idea | [Discussions, Ideas](https://github.com/HugoLopes45/undoturn/discussions/categories/ideas) |

Before you ask, run `undoturn doctor`. It checks the hooks, the store and the recent hook errors. Replace your user name and private paths before you paste its output.

UndoTurn is maintained by one person. Answers are best effort.
