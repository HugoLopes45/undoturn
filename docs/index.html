Codex CLI removed its experimental /undo in January 2026 (openai/codex#8804). The request to bring it back (openai/codex#9203) is still open. UndoTurn gives undo back to Codex, and to all the other agents.

How it works

  1. You send a prompt. UndoTurn records the files.

    The hook stores what changed since the last turn. It follows .gitignore, but it still records .env files unless .undoturnignore excludes them.

  2. The agent runs rm, mv and sed -i.

    UndoTurn compares the files themselves, not the tool log of the agent. A change from a shell command is undone like any edit.

  3. You undo. The files come back.

    A durable journal resumes interrupted recovery and records completed operations. Filesystem changes and journal progress are not atomic against other writers.

Download UndoTurn

UndoTurn needs macOS 14 or later. Download the app, universal, signed and notarized, or the CLI only from the latest release. To build from source instead, clone the repository. Then run undoturn init once in your project. It adds the hooks to all supported agents and registers the project. undoturn uninstall removes the hooks. The history stays.

Yes, unless you exclude them. UndoTurn records .env files even when .gitignore ignores them, so that an undo can restore them. File copies are not redacted. They stay on your Mac with mode 0600. To keep them out, list them in .undoturnignore. The user guide tells how to remove versions already stored.

A change made during a turn belongs to that turn, so an undo of that turn also undoes your change. A change made after the turn is safe: undo keeps it.
